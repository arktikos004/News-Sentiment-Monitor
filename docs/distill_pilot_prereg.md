# 預先聲明：中文小模型蒸餾的初步實驗（探索性）

> **本文件與 `tools/distill_pilot.py` 必須在訓練學生模型之前定稿並 commit。**
> 切分、模型設定與判定門檻寫死在工具開頭，與本文件一致；結果出來後不得更改。

- 撰寫日：2026-10-06
- 撰寫時的狀態：**學生模型尚未訓練，任何模型都還沒有對測試集做過預測。**
  設計切分時看過的只有：各集合的則數與教師標籤分布、兩個教師之間的一致性（見下方參考值）、輸入長度、
  測試集與開發期之間有沒有重複標題。
- 性質：探索性的初步實驗，用來判斷「蒸餾」值不值得在實戰期投入人工標注驗收。不是確認實驗，也不接上線上流程。

## 背景

台股中文標題目前由 Gemma 4（`gemma-4-26b-a4b-it`，經 Gemini API）逐則評分：每則約 1.4 秒、受免費額度限制，標題也要送到雲端。
正式情緒模型 `bert-combined` 以英文語料訓練，讀不懂中文標題。如果能把語言模型的判讀蒸餾成可在本機 CPU 執行的中文小模型，
評分就不必外送，也不受額度限制。

語言模型只給標籤（one-hot），沒有機率分布可學，所以這是以教師的硬標籤訓練學生。

## 要回答的問題（單一）

**以線上評分器（教師）在 2026-09-22 之前的 5,820 則評分訓練的中文小模型，在之後的 1,370 則上，
與教師的判讀是否足夠一致，尤其是教師判為負面的標題？**

這裡的「一致」是與語言模型一致，不是準確率：台股中文標題沒有人工標注可對照（現有 120 則人工標注都是美股英文標題）。

## 資料

- 快照：預警分數庫 `alert_scores.db`（2026-10-06 自加密的狀態封包解出），SHA-256
  `1d8d7785caa997d80df53ae44b43da4980503554cac4c2ee59356e161a9f2247`。只在本機，不進 repo；工具以 `--expect-sha256` 核對。
- 教師：`llm-gemini:gemma-4-26b-a4b-it+thinkingLevel=minimal`（`config.ALERT_SCORER`）評過的 (個股, 標題) 共 7,190 則，
  發布日 2026-08-13 至 10-06，49 檔台股。盤勢報導標題依看板規則排除（線上本來就不送評分，此快照中為 0 則）。
- 參考評分者：本機 `gemma3:27b`（`config.ALERT_SCORER_LEGACY`）。**只用來對照，不進訓練。**
  Gemma 條款（2026-04-01 版）把「以 Gemma 輸出產生的合成資料訓練的模型」算作衍生模型，適用 Gemma 1 至 3n；
  Gemma 4 以 Apache-2.0 釋出，不適用這個定義。

## 切分

| 集合 | 規則 | 則數（負面／中性／正面） |
| --- | --- | --- |
| 測試 | 發布時間 ≥ 2026-09-22T00:00Z（含 9 個交易日） | 1,370（113／400／857） |
| 驗證 | 切點之前的標題群組，依群組第一列的標籤分層抽 15%（seed 42），只供學生早停 | 891（102／271／518） |
| 訓練 | 切點之前的其餘群組 | 4,929（561／1,489／2,879） |

- 群組＝標題經 NFKC 正規化、去掉標點與空白、轉小寫後的字串。同一則標題掛在多檔個股底下，或只差標點、全半形，
  都算同一群組，整組只落在一個集合（開發期 5,820 則共 5,312 個群組）。
- 群組內任一列在切點之後，整組歸測試（此快照中為 0 則）。測試集與開發期之間沒有重複的群組。
- 驗證集用 `newssent.ml.dataset.grouped_stratified_split` 切出，比例取整後的餘數併入訓練。

## 輸入

與教師評分時看到的資訊相同：目標公司（`alert_recorder.scoring_target`，例：台積電（2330））與標題，
以 `build_target_text` 組成目標導向輸入，transformer 端還原成 sentence pair。
輸入長度中位數 46 字、第 99 百分位 83 字；max_length 128 截斷時只砍標題尾端（超過 120 字的有 8 則）。

## 模型（固定，不調參）

| 模型 | 設定 |
| --- | --- |
| 學生 | `google-bert/bert-base-chinese`（Apache-2.0），沿用 `TransformerModel` 的預設值：學習率 2e-5、最多 8 個 epoch、以驗證集 Macro F1 早停（patience 2）、balanced class weight、batch 32、max_length 128、fp16、seed 42 |
| 基準一 | 全猜訓練集的多數類 |
| 基準二 | 字元 1–3-gram TF-IDF＋邏輯迴歸（balanced）。現有的 `tfidf_lr` 用詞 n-gram，對不分詞的中文無效 |

學生只訓練一次；不比較多個預訓練模型，也不依測試結果挑選任何設定。

## 指標

| 指標 | 用途 |
| --- | --- |
| Cohen's κ（學生對教師，3 類） | **判定指標一** |
| 負面召回率：教師判為負面者，學生也判為負面的比例（Wilson 95% CI） | **判定指標二**（預警只看負向偏離，漏判負面的代價最高） |
| 一致率（Wilson 95% CI）、Macro F1、各類精確率與召回率、3×3 混淆矩陣 | 報告用 |
| 推論速度：CPU 與 GPU 每則毫秒（批次 64，`newssent.ml.evaluate`）、CPU 逐則延遲 | 報告用 |
| 與參考評分者在同一批測試列上並列 | 報告用 |
| 每日分數 Spearman；以學生分數重算的警示與教師警示的重合 | 次要、只描述（z 值的基準窗多半落在訓練期，學生在那段是對訓練資料預測，對學生偏樂觀） |

## 判定（依序套用）

1. κ ≥ 0.60 且負面召回率 ≥ 0.80 → **初步可行**：下一步以人工標注驗收。
2. κ ≥ 0.60 但負面召回率 < 0.80 → **部分可行**：可做初篩，負面仍交給語言模型。
3. κ < 0.60 → **不可行**。

門檻的依據：κ 0.60 與換線上評分器時的採用門檻相同（`docs/scorer_switch_prereg.md`）；
負面召回率 0.80＝教師判為負面的每 5 則，學生最多漏 1 則。門檻由開發者於 2026-10-06 定案。
TF-IDF 基準與參考評分者只並列，不進判定。

參考值：兩個教師之間（參考評分者對教師）。撰寫本文件前已計算，不涉及學生模型。

| 範圍 | 則數 | 一致率 | κ | Macro F1 | 負面召回率 |
| --- | --- | --- | --- | --- | --- |
| 全部重疊 | 6,240 | 84.2% | 0.713 | 0.800 | 97.7%（但參考評分者判為負面者，只有 65% 是教師的負面） |
| 測試窗內重疊 | 420 | 85.5% | 0.705 | 0.794 | 28/29 |

## 不做的事

- 不調超參數、不換預訓練模型，也不依測試結果修改切分、輸入或門檻。
- 測試集只評估一次。若因程式錯誤必須重跑，在結果文件的「修訂」一節寫明原因與前後差異。
- 不接上線上流程：網站的評分器不變，學生模型的權重只留在本機。
- 不拿參考評分者（Gemma 3）的標籤訓練。
- 不把任何標題放進 repo：逐則預測只存在本機，結果文件只放彙總數字。

## 已知限制

- 與語言模型一致不等於準確：學生會連教師的錯一起學。
- 測試窗只有兩週（9 個交易日），教師判為負面的只有 113 則，負面召回率的 95% 信賴區間寬約 ±7 個百分點。
- 只跑一個 seed。
- 教師標籤經 Gemini API 取得；該 API 的條款與本實驗的立場見 [DATA_SOURCES.md](../DATA_SOURCES.md)。
