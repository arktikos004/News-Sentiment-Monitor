# mops-data：證交所上市公司每日重大訊息

本分支只存放臺灣證券交易所的官方開放資料「上市公司每日重大訊息」，由 `.github/workflows/mops.yml`
每天自動累積（收集程式：`backend/newssent/data/mops.py`），供網站預警卡的「新聞與公告對照」使用：
列出公司在預警當日往前 3 個交易日（含當日）發布的重大訊息主旨。

## 為什麼要自己累積

這份開放資料沒有查詢參數，每天清晨約 05:00 換成前一個發言日的全部公告。錯過的那一期無法再取得，
所以本分支**只新增、不覆寫**：一般 commit，從不 force push。同一期稍後再抓到新的公告只會補上，已收的列不刪不改。

平臺登錄的 CSV 與證交所 OpenAPI 兩個出口都抓，一邊失敗不影響另一邊。

此開放資料依政府資料開放授權條款（Open Government Data License）進行公眾釋出，
使用者於遵守本條款各項規定之前提下，得利用之。
政府資料開放授權條款：<https://data.gov.tw/license>

每個檔案的 `meta` 也記錄了顯名聲明（`attribution`）、平臺資料集頁面（`dataset_url`）、實際來源網址與取得時間；
同一期補過公告時另有 `updated_at` 與 `update_source_url`。

## 檔案格式

| 路徑 | 內容 |
| --- | --- |
| `t187ap04_l/<年>/<出表日期>.json` | 該期的全部公告：出表日期、發言日期、發言時間、公司代號、公司名稱、主旨、符合條款、事實發生日 |

每個檔案是 `{"meta": {...}, "rows": [...]}`，`rows` 保留官方的字串值（民國日期；發言時間為 `HHMMSS`，小時省略前導零）。
一期的「出表日期」是檔案產生的日子，公告本身的日期看每列的「發言日期」。

**不收「說明」欄**：說明全文可能含個人資料（例如人事異動的姓名與經歷），`meta.omitted_fields` 記錄了略去的欄位。
全文請至[公開資訊觀測站](https://mops.twse.com.tw/)查閱。
